# ☁️ Consterna Cloud

Un frontend interactivo (interfaz de usuario) para un almacenamiento en la nube personal, diseñado desde cero con un diseño limpio y moderno.

---

## 🎨 Características

- **Diseño Moderno:** Interfaz web intuitiva para gestionar archivos.
- **Responsive:** Adaptable para visualización.
- **Ligero:** Construido sin frameworks pesados, puro HTML/CSS/JS por el momento.

## 🚀 Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🛠️ Estado del Proyecto

Actualmente en fase de desarrollo de interfaz (Frontend). El proyecto servirá de base visual para conectarse próximamente a un backend (API) de gestión de archivos reales en Python.
